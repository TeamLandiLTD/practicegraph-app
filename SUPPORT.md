# Support

PracticeGraph is maintained by a small team. Here is where each kind of question goes.

| I have… | Go to |
| --- | --- |
| A problem using the app | [Troubleshooting](docs/TROUBLESHOOTING.md) first, then a [bug report](https://github.com/TeamLandiLTD/practicegraph-app/issues/new?template=bug_report.yml) with the version, operating system and `practicegraph doctor` output |
| A question about what a number means | [FAQ](docs/FAQ.md), [Understanding Usage](docs/USAGE_EVIDENCE.md), [Token price tracker](docs/TOKEN_PRICES.md) |
| A question about privacy | [Privacy](docs/PRIVACY.md); if it is still unanswered, open an issue and we will improve the page |
| An idea | [Suggest an idea](https://github.com/TeamLandiLTD/practicegraph-app/issues/new?template=idea.yml) |
| A suspected vulnerability | [SECURITY.md](SECURITY.md), privately. Never in a public issue. |
| A correction to a curated edition | An issue titled with the edition name and date. Editions are published separately from this repository; see [Hosted content](docs/HOSTED_CONTENT.md) |

Never attach session logs, prompts, tokens, databases or private paths. A minimized synthetic example is the right shape for a parser mismatch.

There is no guaranteed response time. Issues that include a clear reproduction and the `doctor` output are the ones that get fixed first.
