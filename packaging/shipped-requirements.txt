# --require-hashes turns a version pin into an artifact pin. A version
# alone still trusts whatever PyPI serves under that name today; these
# hashes were taken from the artifacts on 2026-07-26 and a substituted or
# re-uploaded wheel now fails the install rather than landing inside a
# process that reads someone's logs.
#
# tzdata is pure data (zoneinfo tables, no executable code). tzlocal is
# five files and we call exactly one function from it - see
# docs/PER_USER_INSTALL_PLAN.md for the plan to vendor it away entirely.
#
# Regenerate:  pip download --no-deps -d <dir> <pins>  then sha256 each file.
